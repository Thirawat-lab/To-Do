# แอปรายการงาน (Todo App)

React + Vite + Tailwind CSS v4 + lucide-react

## เริ่มต้นใช้งาน

```bash
npm install
npm run dev      # เปิดโหมดพัฒนา
npm run build    # สร้างไฟล์ production ในโฟลเดอร์ dist
npm run preview  # ดูตัวอย่างไฟล์ที่ build แล้ว
```

ข้อมูลเก็บใน React state เท่านั้น รีเฟรชหน้าแล้วข้อมูลจะหาย
